# StudyHub – Student Learning Platform

## About the Project
StudyHub is a student learning platform designed to make learning simple, easy, and enjoyable.

It provides students with information about different subjects and helps them improve their learning skills.

## Features
- Welcome section with a Get Started button.
- Explore Our Subjects section.
- Web Development subject.
- Mathematics subject.
- English subject.
- About StudyHub section.
- Study Tips button.
- Contact Us form with name, email, and message fields.
- Responsive and user-friendly design.

## Technologies Used
- HTML – To create the structure of the website.
- CSS – To style and design the website.
- JavaScript – To add interactive features.

## Project Purpose
The purpose of this project is to create a simple educational website where students can explore different subjects and improve their knowledge.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open the index.html file in a web browser.
4. Explore the StudyHub website.
